# Sovereign AI Stack v0.2.0-alpha

This is an **early research preview** of components for verifiable local AI.

**Current Capabilities** (Alpha):
- NLI-based grounding gate with calibration
- Merkle-based audit chain with basic proofs
- Simple governed ReAct agent loop
- Local-first RAG patterns

**Important**: This is experimental code. It is **not production ready**. See [LIMITATIONS.md](LIMITATIONS.md) and [KNOWN_GAPS.md](KNOWN_GAPS.md) for details.

Intended for researchers and engineers exploring sovereign AI concepts in regulated environments.

Feedback and contributions welcome.
